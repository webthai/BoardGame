## ออนไลน์ — ออกแบบอย่างไร
- **Action log replay:** ทุกเครื่องเล่น action ชุดเดียวกันตามลำดับเดียวกัน (ค่าสุ่มทั้งหมดอยู่ใน action) · แผ่น `Rooms` + `R_<CODE>` (แถวละ 1 action) · `krAct` ต่อท้ายได้เมื่อ `idx` = จำนวน action ปัจจุบัน ไม่งั้น `stale`
- ฝั่งเกม: คิว `Q` + `take(...types)` · `emit(a)` · `pollLoop` · `beginGame(cfg, plist)` → `orderPhase()` → `gameLoop()`
- Action: `orderRoll {i,v}`, `roll {value,r,q,k}`, `useItem {id}`, `duelRoll {s,v}`, `special {t,d,v}` · UI อนุญาตเฉพาะผู้เล่นของเครื่องนั้น (`mine(i)`) · 1 เครื่อง = 1 อัศวิน (2-4 คน)
- **Rejoin:** `{room, slot}` ใน localStorage → poll `since=0&cfg=1` → ใส่ action เข้าคิวก่อน `beginGame` → replay เร็ว (`replaying` = true → `tween()` จบทันที, ข้าม sleep/เสียง/อนุภาค/log)
- ออนไลน์: ลุคอัศวิน `auto:true` จะถูกแทนด้วย `SLOT_LOOKS[slot]` ตอน `beginGame` (หน้าตาต่างกันตามลำดับเข้าห้อง) · สีเริ่มต้นช่อง 0 สุ่มเมื่อเลือกโหมดออนไลน์

## รอบ 10 — อัศวิน/แอนิเมชัน (ผู้ใช้ขอ: อัศวินโค้งมนเหมือนรูปอ้างอิงที่ส่งมา, 4 ตัวหน้าตาต่างกัน, เลขเหนือหัว, ประกาศทุกแอคชั่น, ขี่ม้า, อนิเมชันสมูท 60/120)
- **อัศวินชิบิ** (`makeKnight(color, look)`): หัวโตทรงกลม ตาโตมีไฮไลต์ แก้ม หมวกเหล็กมี **สันตามภาพ** (Shape+Extrude) + แผ่นป้องกันหู, เข็มขัดกางเขนทอง, เกราะไหล่, ปกคอ + **ผ้าคลุมตาข่าย 9x9 โบกตามลม** (`waveCape`), อาวุธ/โล่ติดที่ pivot แขน · วัสดุแยกรายตัว (`km()`) เพื่อ `flash()` · สเกลในฉาก `KS = .7`
- `look` = {skin, face, hat, hair, weap, shield, cape, auto} (ดัชนีใน `OPTS`; สี = สีเสริมตามสายอาชีพ) · `SLOT_LOOKS` = 4 ลุคเริ่มต้นต่างกัน (แดง: หมวกสัน+ดาบ+ผ้าแดง / น้ำเงิน: หมวกเขา+ขวาน+โล่ / เขียว: ผมสั้นส้ม+ดาบ+โล่ / เหลือง: มงกุฎ+ผมบลอนด์+ผ้าม่วง) · แก้ผ่านปุ่ม "ปรับแต่ง" (พรีวิว 3D หมุน)
- **ป้ายเหนือหัว** (`makeTag`/`drawTag`): วงกลมทอง = **เลขช่องปัจจุบัน** (เริ่ม = "เริ่ม") + ชื่อผู้เล่นสีเกราะ · วาดใหม่เฉพาะตอน `pos` เปลี่ยน (เรียกจาก `hud()`) — ถ้าผู้ใช้หมายถึงเลขอื่น (เช่นลำดับเทิร์น/HP) แก้ที่ `drawTag`
- **Tween ตามเวลาจริง** (`tween(dur, fn)`, `ptween(p, dur, fn)` นับ `p.tw`): ทุกการเคลื่อนไหวคำนวณจาก dt → ลื่นเท่ากันที่ 60/120Hz · `stepTo` (กระโดดทีละช่อง + บีบตัว + ท่าเดิน + ฝุ่น), `walk`, `warp` (หดตัว→ย้าย→ขยาย), หันตัวนุ่มนวลใน loop (`p.face`) · ตัวจำกัดเฟรมเรต `capMs` เลือก 60/120 ที่หน้าตั้งค่า (จังหวะคงที่), ตัววัด fps ใน `#fps`
- **ช่องม้า** (`rideHorse(p, n, to)`): ประกาศ "ขึ้นม้าวิ่งไปข้างหน้า N ช่อง" → ม้าหันหัว → อัศวินกระโดดขึ้นอาน (`SADDLE`, `sitPose`) → ม้าควบตามเส้นทาง (CatmullRomCurve3 ผ่านจุดกลางช่อง, `gallop()` ขยับขา) → ลงม้า → **ม้าเดินกลับที่เดิมเบื้องหลัง** (ไม่บล็อกเกม; `hd.busy` promise กันม้าถูกใช้ซ้อน) · ม้าเป็นพร็อพประจำช่อง `PROPS[n]` ทรงโค้งมน ขาแยก pivot · replay = วางอัศวินที่ปลายทางทันที
- **ประกาศทุกแอคชั่น:** `say()` แสดงแถบข้อความล่างจอ + บันทึก `logAdd()` ในกล่อง "📜 เหตุการณ์ล่าสุด" มุมขวา (7 รายการล่าสุด, ซ่อนบนจอ ≤700px) · ข้อความ: ทอยได้ X → เดินหน้า N ช่อง, ถึงจุดพัก, กับดัก, หีบ, NPC, ม้า (หลายขั้น), ดวล, มังกร ฯลฯ

## กราฟิก/กล้อง/UI (รอบ 8-9)
- กล้อง orbit เอง (`orb`): ลากหมุน 360°/ก้มเงย, ล้อเมาส์/บีบ 2 นิ้วซูม, `setView()` รีเซ็ต, 🔭 สลับตามอัศวิน/ทั้งกระดาน
- เงา (`sun` ตามจุดที่กล้องมอง ±28), ท้องฟ้า shader, หมอก FogExp2, texture หญ้า/หิน, กระเบื้อง InstancedMesh + ฐานหิน, คบไฟจุดพัก, พร็อพประจำช่อง (หนาม/หีบ+ดาว/ม้า/หลุมดำ/NPC), ต้นไม้/หิน/ดอกไม้/ภูเขา/บ่อน้ำ/เมฆ, ปราสาท+เจ้าหญิง+มังกร, อนุภาค `burst()` (ข้ามตอน replay)
- กราฟิก **สูง/ต่ำ** (`GFX.hi`, `applyGfx()` ตอน `beginGame`; มือถือเริ่ม "ต่ำ"+60fps)
- UI: `.glass`, ลูกเต๋าใหญ่, ปุ่มทอย `pulse`, การ์ดผู้เล่น `.pc`, ฟอนต์ Kanit
- **ข้อควรระวังโค้ด 3D:** (1) `Group.add()` คืนค่า Group ไม่ใช่ลูก → ห้ามต่อ `.rotation` ท้าย `add()` (ใน helper ที่คืนค่า mesh เช่น `part()`/`add()` ของม้า ต่อได้) · (2) คีย์แคช `G('...')` ต้องไม่ซ้ำกันข้ามพร็อพ · (3) three r128: ไม่มี sRGB/ToneMapping/CapsuleGeometry, `metalness` ไม่เกิน ~.3 (ไม่มี envMap) · (4) วัสดุแชร์ (`M()`) ห้ามแก้ emissive/สีรายตัว — ของอัศวินใช้ `km()` แยกรายตัว · (5) ห้ามสุ่มในตรรกะเกม (สุ่มได้เฉพาะภาพ/เสียง)

## บั๊กที่ค้าง / ข้อจำกัด
1. **รอบ 9-10 ยังไม่ได้ทดสอบจริง** — จุดเสี่ยง: ความลื่นเมื่อเงา+ผ้าคลุมคำนวณทุกเฟรม (ถ้าช้าให้ปิดเงา/เลือกกราฟิกต่ำ หรือเลิก `computeVertexNormals` ใน `waveCape`), เส้นโค้งม้าตัดมุมตรงทางโค้งของกระดานงูเลื้อย, ท่านั่งบนม้า (`SADDLE`, `sitPose`) อาจต้องจูนตำแหน่ง, ป้ายเหนือหัวบังกันเมื่อหลายตัวอยู่ช่องเดียวกัน, `setColorAt` ของ InstancedMesh ใน r128
2. ช่องม้าที่ `to <= n` (ถ้าแก้ MapConfig ให้ปลายทางอยู่ก่อนช่องม้า) ยังไม่มี fallback → CatmullRom อาจพัง; ค่าเริ่มต้นเป็น +4..+9 เสมอ จึงไม่เกิด
3. ออนไลน์/rejoin/บอร์ด 500-1000/เสียง ยังไม่เคยทดสอบจริง (ออนไลน์ใช้ไม่ได้จนกว่าผู้ใช้ติดตั้ง Code.gs v3)
4. โควตา Apps Script: poll ทุก 1.5-4 วิ ต่อเครื่อง (~90 นาที/วัน)
5. ถ้าผู้เล่นปิดหน้าตอนถึงตาเขา เกมค้างรอ (แก้ด้วย "กลับเข้าห้อง") · สถานะแคตตาล็อก "กำลังเล่น" ผูกทั้งเกม ไม่ใช่รายห้อง

## หลักการออกแบบ (ห้ามลืม)
1. **สถานะทั้งหมดอยู่ใน `S`** (JSON ล้วน): `turn, over, dragon, size, seed, mapSrc, map, busy, players[]` (i, name, color, look, pos, hp, maxHp, freeze, items[], shield, boost, six) · ส่วนภาพ (`mesh, tag, tw, face, mounted`) เป็นแค่ตัวแสดงผล ห้ามส่งออนไลน์
2. **ห้ามสุ่มใน dispatch/orderPhase/askDuel/askSpecial** — ค่าสุ่มต้องมากับ action · เอฟเฟกต์ภาพ/เสียง/อนุภาคสุ่มได้
3. ตรรกะเกมแยกจากแอนิเมชัน · popup แสดงอย่างเดียว ผลมาจาก action ในคิว · แอนิเมชันใหม่ต้องเป็น tween (ไม่ใช้ setTimeout คุมการเคลื่อนไหว) และต้องจบทันทีเมื่อ `replaying`
4. กระดาน: `tilePos(n)` งูเลื้อย 10 ช่อง/แถว (x = -9..9) · Checkpoint = n % 10 === 0 (อยู่ริมกระดาน คบไฟวางด้านนอก) · `tileXZ(p, n)` = ตำแหน่งยืนของผู้เล่น (มี offset 2x2 กันทับ)

6. `ITEMS`/`ITEM_IDS` เป็น `let` (โหลดจาก Sheet ได้) · ออนไลน์ใช้ `ITEM_IDS` ตาม config ห้อง

## กติกาที่ทำแล้ว
- ช่อง: BlackHole ข้าม 1 ตา · Horse ขึ้นม้าไป `value` · NPC `r<.5` ทอยฟรี ไม่งั้นถอยตามแต้มเต๋า · SpecialNPC เลือกเป้า+ทิศแล้วทอยเต๋าพิเศษ (ไม่ส่งใครเกิน SIZE-1) · Danger HP-1 · Treasure ไอเทมสุ่ม (กระเป๋า 3)
